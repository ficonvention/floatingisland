# Floating Island website

Static site for www.floatingisland.co.kr (GitHub Pages).

- Edit `build.py` and run `python3 build.py` to regenerate, or edit the `.html` files directly.
- Styles: `css/style.css` · Script: `js/main.js`
- Images currently load from the Wix CDN; replace with files under `images/` when originals are available.
